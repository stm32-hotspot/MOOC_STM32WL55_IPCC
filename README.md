# MOOC STM32WL55 IPCC  in practice

WARNING  : 
    This material has been created in 20xx and is delivered as it is.

## MOOC purpose 

Get practical skills on creation, configuration and run dual core project using IPCC on STM32WL55 MCUs using STM32CubeIDE toolchain.

## Prerequisites
- NUCLEO-WL55JC2 board
- microUSB cable
- PC with preinstalled the following software:
    - STM32CubeIDE (in version at least 1.5.0)
    - STM32WL Cube library (in version at least 1.0.0) → to be installed from STM32CubeIDE (help → Manage Embedded Software Packages → STM32Cube MCU Packages)
